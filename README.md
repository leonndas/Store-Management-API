# Baozi Store API

REST API developed with Java and Spring Boot for managing customers, products and orders.

## Technologies

- Java
- Spring Boot
- Spring Data JPA
- MySQL
- Maven
- Postman

## Features

- Customer CRUD
- Product CRUD
- Order CRUD
- RESTful endpoints
- JSON requests and responses

## Project Structure

- model
- repository
- service
- controller
